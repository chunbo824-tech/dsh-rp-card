# 阶段素材包：卡跑起来"没内容"时怎么补

## 什么时候用

触发都对、结构也完整，但实际跑起来只有关系分析、心理活动、行为边界，缺少可直接展开的素材。这是"稳定但干"，不是路由问题，不要再改触发。

## 核心判断

素材要补的是**信息量**，不是措辞量。

单轴伪丰富判据：把每个素材单元各压成一句话，如果两个单元的压缩句可以互换而不损失信息，就是同一条轴上的重复——删掉一个，把篇幅换成另一条轴上的内容。

常见单轴：同一个关系状态换八种说法、同一个心理动机反复解释、同一类反应只换形容词。

不同轴才有信息：不同对象下的反应差异、身体不同部位的独立反应、不同场景下的姿态与声音、被特定动作触发的独特行为、事后态度的差异。

## 怎么补（本平台的正确姿势见 docs/5 §5.3）

1. 先补**阶段核心**（≤600 字，挂阶段字段锚）：本阶段味道、关系与界线、角色反应规律。
2. 再补**细分素材**（挂内容锚，按需加载）：
   - 语气锚 3–5 条；
   - 反应链每条 60–120 字；
   - 事件种子每个 80–150 字。
3. 一个条目只装一类东西，不要混装。

## 不要做

- 不要把一整包 2000 字挂到阶段字段上（那是常驻，必然超预算）。
- 不要写完整事件正文与可照抄的脚本。
- 不要靠堆同义词充数。
- 不要为了"厚"而牺牲阶段隔离（后期称呼、关系层级提前出现）。

## 验证

| 检查 | 门槛 |
|---|---|
| 每阶段有核心条目且 ≤600 字 | 必须 |
| 常驻合计 ≤800 字/轮 | 必须 |
| 每条素材做过单轴压缩自检 | 必须 |
| 语气锚全卡 ≤20 条 | 建议 |
| 反应链与事件种子没有写成正文 | 必须 |
