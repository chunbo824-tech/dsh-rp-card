# 题材原型索引

只在用户点名要这类结构时读。没点名就用通用结构和用户的设定，不要主动往这些原型上靠。

下面只写**结构差异**，不写内容。所有原型都必须满足 docs/5 的玩家代理边界与预算约束。

## 关系向（成人向常见）

| 原型 | 结构要点 | 平台注意 |
|---|---|---|
| 渐进堕落 | 阶段推进 + 每阶段关系可感知变化；阶段之间要有可见的"回不去"标记 | 阶段字段挂格式字段锚；每阶段一条核心条目 |
| 反制／夺回 | 与上一类镜像：从低关系态往回升；需要"察觉—犹豫—行动"三段 | 同上，方向反过来 |
| 单一征服 | 目标固定、多条路径到达；路径差异体现在对方反应而非结局 | 路径用内容锚，不要为每条路径建常驻 |
| 多目标并行 | 多角色各自独立阶段；禁止用同一套反应模板 | 每角色独立条目，禁止共用反应链 |
| 保密／风险 | 第三方在场或可能撞见；风险状态是独立字段 | 风险状态用格式字段锚或前端锚点词（见档案页 2.12） |
| 多视角 | 同一世界内多个视角切换 | 平台无 entry constant 开关；只能在开场/档案页选定视角，写进状态字段 |

## 非成人向但常被点名

| 原型 | 结构要点 |
|---|---|
| 守护／陪伴 | 关系温度 + 事件守护；冲突来自外部而非关系内部 |
| 悬疑解谜 | 信息分段揭示；世界书按证据锚触发，注意防自触发 |
| 经营模拟 | 资源与时间循环；结算规则挂 END，不常驻 |

## 选择原则

1. 用户没点名就不选原型，直接从他的设定推导结构。
2. 选定原型后，只借鉴它的**阶段划分与状态字段**，不套它的剧情。
3. 多目标是复杂度陡增项：角色数 >3 时，先确认用户是否真的要全部推进，否则建议收敛到 2–3 个。
