# 补充材料（按需读取）

这里的东西**不进主流程**，只在用户明确提到相关要求时才读。

| 文件 | 什么时候读 |
|---|---|
| `阶段素材包.md` | 用户说"卡跑起来没内容""不够厚""总是干巴巴讲道理"，或明确要按阶段做内容加厚时 |
| `题材原型索引.md` | 用户点名要 NTR／NTL／守护／禁忌后宫／多视角这类特定题材结构时 |
| `审查清单.md` | 用户要求"帮我审一下这张卡"或交付前想再自查一遍时 |
| `数值卡.md` | 卡需要数值/成长/累积/事件结算（战斗、升级、成人向累积）**且已向玩家说明优缺点并获同意**后 |

注意：`数值卡.md` 必须先征求玩家同意再读；其余文件直接读即可。

规则：

- 不要在每张卡开工时读这些文件，会白占上下文。
- 读到了也不代表必须照做；主流程的四份规范仍然优先。
- 与平台约束冲突时，以平台约束为准（例如常驻预算、字段默认值）。
