# 平台键名对照（2026-11-12 权威字段库版）

平台每次导出会**独立随机**抽一套同义键名（同一张卡 2 小时内导出 3 次，40 键里每次只有 7–10 个同名，值完全一致）。所以：

- **登记 = 插件能理解这个键**；`audit` / `ingest` 不再把它当未知字段。
- **映射 = v2 导出时把值写到对应 v2 键**；未映射键在导出时原样保留（source 导出原样，v2 导出进 extras）。
- **content = 卡内容字段**，按 `FIELD_ALIASES` 读入，导出用规范字段重写。
- **只读**：标签（平台机械规定，插件不写标签）、自动总结（只理解，不参与导出）。

完整字段库（单一来源，2026-11-12 v1 定稿）：`references/platform-fields.json`。本表由它生成/校验，改同义词必须两处同步并跑 `tests/platform-fields.test.mjs`。

## 自动总结（只登记，不参与导出）

- 平台字段是 `summary_config`，子键：`big_prompt` / `small_prompt` / `model_config {name, provider}` / `enable_status`。默认骨架与平台一致。
- **`enable_status` 实测（两次对照）**：`1` = 开启（带自定义提示词）；`2` = 关闭（默认空骨架）。**1/2 没有反**。
- 平台导入会读取 extras 里的 `ai_summary_config` / `ai_s_config` 并据此显示开启——所以 v2 导入件必须把这两个键和 `summary_config` 一起剔除、保持默认关闭；否则用户导入后会看到自动总结被打开。
- **关闭链路已实测**：用 40 键导入件导入后，平台显示关闭；再导出的文件里 `summary_config` 为 `enable_status: 2`、提示词为空（文件 G）。
- 随机键 `ai_s_config` / `ai_summary_config` 只登记，不映射；插件创作的 v2 导入件不输出自动总结内容。

## 图片 / 音乐 / 封面（2026-11-12 实测）

图片是**本地上传**，但平台导出件里存的是**平台 CDN 的 URL**，不是本地路径、不是 base64：

| 字段 | 导出值示例 | 说明 |
|---|---|---|
| 封面 `cvr` | `https://catai.wiki/<id>/cover` | 带协议头 |
| 桌面背景 `back_img` | `https://catai.wiki/<id>/bg` | 带协议头 |
| 手机背景 `bg_mobile` | `https://catai.wiki/<id>/mobile` | 带协议头 |
| CG 图片 `cg_book[].image_url` | `catai.wiki/<id>/w=3000` | **不带协议头**，读取/回填时要补 `https://` |
| 音乐 `music.tracks[].url` | `https://bg-music.catai.wiki/music/<id>.mp3` | 平台音乐 CDN |
| 封面缩略 `cvr_tiny` | `""` | 设置封面后导出仍为空 |

## 预设对话 / 快捷指令 / CG 结构

- `ps_chats[]`：`{title, chats: [{query, answer}], suggested_questions: []}`
- `shortcut_commands[]`：`{label, command_text}`
- `cg_book[]`：`{id, image_url, key_mode, key_region: ["ai"], keys: [], map_area, name, show_name, unlock_hint, show_unlock_hint, is_gallery, gallery_group, value_type, image_configs: []}`
- `regex_replaces[]`：在 `{scope, title, is_enable, match_regex, replace_text}` 之外还有 `group` 与 `is_only_render`（可为 `null`）。
- 预设对话 `ps_chats` / `preset_chats`：**平台导出可能不带这个字段**（实测平台界面里预设对话仍在，但导出件为空）。验证以平台界面为准；插件只能保留已有值或提示在平台重建。同类：`cvr_tiny` 有封面但导出为空。

## 简介 ≠ 自动总结

导出件里的 `summary` / `abs_txt` / `smry` / `abstract` 指**简介**（`sum_info`）；`summary_config` 才是自动总结。两者不是一回事；简介是第一部分可选产出，自动总结插件不产出。

## 推荐问题（可点击行动建议）

- AI 输出 `<suggested_questions>…</suggested_questions>` 是输出标签，平台渲染成按钮，不是导出字段，别名库不收录。
- 导出字段 `sq` / `suggest_q_after` 的同义键见上表；插件只登记、不主动生成。
- 是否接进卡里记在 `创作指南吸收-plan.md` D5，待平台实测。

## 世界书字段

| 字段 | 含义 |
|---|---|
| `key_region` | 扫描来源位掩码：2=只扫玩家输入，4=只扫 AI 输出，6=两者都扫；默认 6 |
| `value_region` | 影响范围位掩码：1=提示词，2=前置词，4=后置词；可组合 |
| `sort` | 插入顺序，0–9999；默认 0 |
| `depth` | 扫描深度 0–20；默认 0；例外见 docs/1 |
| `probability` | 触发概率，默认 100 |
| `value_type` | 默认 0 |

平台键名：`sum_info`。用户同意代写简介时，最终 JSON 写 `sum_info`；v2 导出键名已包含该键。
